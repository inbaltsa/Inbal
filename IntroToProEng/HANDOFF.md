מסמך זה מרכז את **כל ההקשר** הדרוש כדי להמשיך לעבוד על הלומדה ביוזר/שיחה חדשה,
בלי ההיסטוריה של השיחה שבה היא נבנתה.

## 1. מה זה

לומדת **למידה עצמית** (self-study) לפרק 2 של קורס *מבוא להנדסת תהליכים*:
**מדידה, אינטרפולציה והתאמת עקומות**. נבנתה מתוך מצגת הרצאה
(`source-deck-chapter2.pptx`), והמטרה: שהסטודנטים ילמדו לבד, עם בדיקות ידע,
ובסוף מבחן מסכם **נספר** שמדווח ל-Moodle דרך **SCORM 1.2**.

קהל: שנה א' סמסטר א', תחילת הסמסטר. הנושא הוא "ערכת כלים" יסודית שתשרת אותם
במעבדות ובקורסים בהמשך.

## 2. הקבצים

```
IntroToProEng/
├── lomda/
│   ├── index.html      ← המנוע + העיצוב (לא נוגעים בשביל שינוי טקסט)
│   ├── content.js      ← כל הטקסט של הלומדה. כאן עורכים תוכן.
│   └── images/         ← גרפים ומשוואות (חולצו מהמצגת)
├── lomda_scorm.zip     ← חבילת SCORM מוכנה להעלאה ל-Moodle
└── source-deck-chapter2.pptx  ← המצגת המקורית
```

**ארכיטקטורה:** הלומדה מונעת-נתונים. כל הטקסט נמצא ב-`content.js` (אובייקט
`window.LOMDA`), והמנוע ב-`index.html` מרכיב ממנו את המסכים. כדי לשנות טקסט —
עורכים רק את `content.js`, בלי לגעת במנוע.

### סכמת התוכן (content.js)
`window.LOMDA = { title, pass:70, screens:[ ... ] }`. כל מסך הוא אחד מ:

- **מסך תוכן:** `{ act, eyebrow, title, blocks:[...], question:{...}|null, examNote? }`
  (או `questions:[...]` — רצף שאלות שכל אחת נחשפת רק אחרי בדיקת הקודמת; ראו מסך 2)
- **חוצץ מערכה:** `{ kind:'divider', act, num, title, sub }`
- **מבחן:** `{ kind:'exam', eyebrow, title, intro, questions:[...] }`
- **מסך ציון:** `{ kind:'result', act }`

**סוגי בלוקים (`blocks`):**
`p` (פסקה) · `scene` (הערת הקשר ירוקה) · `note` · `core` (קופסת הדגשה) ·
`coreTeal` · `list{items}` · `eq{src}` (תמונת משוואה) · `img{src,alt,cap}` ·
`wordmap{items:[{term,gloss,body}]}` · `dialogue{mode:'progressive'|'static',
lines:[{who:'z'|'t',text,stage?} | {turn}]}` · `calibChart{mode}` ·
`comparefits` · `scatter` · `localInterp` (הגדלה בין C=4 ל-6) · `figrow{items:[{src,alt,cap}]}` ·
`logscales{items:[{label,type:'lin'|'log',mark,color}]}` · `decisionTree{...}` ·
`reveal{showLabel,hideLabel,chartTrue?,blocks:[...]}`

**מצבי גרף הכיול (`calibChart.mode`):** `learn-line` (נקודות+קו) · `engage`
(בנייה מדורגת עם סליידר) · `learn` (אזורים+סמנים+ערכים אמיתיים) · `segments`
(קטעים בין כל הנקודות) · `twofits` (שני ישרים כמעט חופפים).

**סוגי שאלות (`question`):**
- `mc`: `{t:'mc', q, opts:[{k,text}], answer:'<k>', fb:{ok,no}}`
- `numeric`: `{t:'numeric', q, answer:<num>, tol, unit, placeholder, fb:{ok,no}}`
- `sort`: `{t:'sort', bins:[{id,label,ava,color}], cards:[{text,correct}], fbOk, fbNo}`
  (ב-`fbNo` אפשר `{n}` = מספר התשובות הנכונות)
- במבחן: `mc`/`numeric` עם `answer` בלבד (בלי `fb` — נבדק ונספר).

## 3. איך ממשיכים לעבוד

1. **עריכת טקסט:** ערכו את `lomda/content.js` (הטקסט שבין המרכאות).
2. **בדיקה מקומית** (ללא שגיאות + צילום): Playwright עם Chromium
   (`PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers`). טוענים `file://.../index.html`,
   `content.js` נטען יחסית. מנווטים עם לחיצות בתוך-הדף:
   ```js
   // המשך דיאלוג מדורג:
   document.querySelector('#screenHost .center .btn.primary').click();
   // מסך הבא:
   document.getElementById('nextBtn').click();
   ```
3. **פרסום כ-Artifact** (לתצוגה חיה): פרסמו `index.html` עם `content.js`
   והתמונות כקבצים נלווים. *הערה:* ה-Artifact הקיים שייך ליוזר שבנה אותו —
   מיוזר אחר פשוט מפרסמים ארטיפקט חדש מהקבצים.
4. **אריזת SCORM מחדש:** מריצים `./build_scorm.sh` (בונה את `lomda_scorm.zip` מתוך `lomda/`,
   כולל manifest ותוספת doctype + UTF-8 ל-index.html, שבלעדיהם העברית עלולה להשתבש ב-Moodle). ב-Moodle: פעילות "חבילת SCORM",
   ותחת ציון — שיטה "הציון הגבוה ביותר".

> ⚠️ **אל תמחקו את ה-try/catch בעטיפת ה-SCORM שב-index.html.** בלעדיו, גישה
> לחלון-האב בתוך iframe חוצה-מקור זורקת שגיאה ועוצרת את כל הטעינה (מסך ריק).

## 4. ההחלטות העיצוביות (זו גם המתודולוגיה)

כל אלה **כללים שנקבעו ויש לשמר** לאורך הלומדה:

**הדמויות:** *הסטודנט העצל זרובבל* (מחפש קיצור, פרגמטי) ו*הסטודנטית החרוצה תרצה*
(רוצה דיוק). בהצגה הראשונה — הניסוח המלא. בבועות — שם קצר. **אף אחד לא צודק תמיד**:
הלמידה היא לדעת מי צודק *הפעם*. (צבעים: זרובבל זהוב, תרצה ירוק.)

**בלי הערות "במבחן תידרשו"** בגוף הלומדה — השאלות לדוגמה עושות את העבודה.

**קול:** לשון **רבים-דובר** ("מדדנו", "ילוו אותנו", "נקבל"). לא גוף שני.
**ניסוח שוויוני מגדרית** (שם-פועל או ציווי רבים), לעולם לא יחיד-זכר.

**שאלות:** **סגורות ונבדקות אוטומטית בלבד** (רב-ברירה / מספרי / מיון).

**מינוח:** **בליעה** (absorbance A), לא "ספיגה/ספיגות".

**עוגן:** ניסוי **כיול ביר-למבר** (בליעה מול ריכוז) רץ לאורך כל הלומדה;
קולבק ב-3.6 — ש-A=εCℓ הוא עצמו תוצאה של לינאריזציה.

**"זניח"** = פחות מ-5% (ההגדרה משתנה בין דיסציפלינות; מוסבר בכוכבית ב-2.2).

**לא להשתמש ב-R²** (מבלבל ולא מדויק במה שהוא אומר). ההבחנה לרגרסיה היא
**נתונים נקיים מול רועשים**, לא "גס מול מדויק". רגרסיה = הדרך ה**אובייקטיבית**
ביותר (לא "מדויקת") — לא תלויה בבחירה שלנו.

**ניסוח:** "ערכים אמיתיים" (העקומה התיאורטית), לא "נתונים". תיוג: "הגרף
התיאורטי להמחשה בלבד".

**מבנה כל חתיכה:** `engage` (ויכוח שמעלה טעות נפוצה) → `learn` (ההסבר שסוגר את
"פער ההנחיה") → `check` (שאלה סגורה). לפעמים גם `סוף דבר`.

**הרעיון המרכזי (החוט):** איך מחלצים מתוך נתונים לא מושלמים **ערך או קשר אמין —
וכמה אפשר לסמוך עליו.** חמש מערכות: 0 עוגן/שאלה · 1 ערך בודד (אינטרפולציה) ·
2 הקשר (התאמה/רגרסיה) · 3 מיישרים (לינאריזציה/לוג) · 4 איך בוחרים + מבחן.

**טכני:** כפתור "הבא" זמין תמיד — גם באמצע דיאלוג מדורג (לא מכריחים להריץ את כל השיחה); דיאלוגים פתוחים (`static`) כברירת מחדל; כפתור "התחלה מחדש"; פס התקדמות; תמה בהירה "נייר" (ירוק של המצגת), RTL,
גופנים Frank Ruhl Libre + Assistant; SCORM 1.2 עם דיווח ציון 0–100 + עבר/נכשל,
ציון עובר 70.

## 5. מצב נוכחי — מה גמור ומה פתוח

**גמור ומלוטש:**
- מערכה 0 (פתיחה + ניסוי כיול, כולל רצף שאלות על שני שלבי הכיול), מערכה 1 (1.1 במלואה; 1.2 — ויכוח "האמצע" ב-C=5.5 + גרף מוגדל), מערכה 2 (2.1–2.4 נבנו מחדש
  עם ויכוחים אמיתיים, כולל גרף נקי מול רועש, אמפירי/פיזיקלי).
- המנוע המלא (כל סוגי הבלוקים/שאלות/גרפים), המבחן המסכם, מסך הציון, ו-SCORM.
- כל התיקונים הלשוניים (רבים-דובר, בליעה, דמויות, ערכים אמיתיים).

**פתוח — צריך העמקה (הדיאלוגים עדיין "מכריזים על נושא", לא מקבעים ידע):**
- **מערכה 3:** 3.2 (לינאריזציה), 3.3 (גרפי לוג), 3.6 (קולבק) — דיאלוגים דלים.
- **4.1** (עץ החלטה) — דיאלוג דל.
- אופציונלי: פיצול/הקלה של מסך ההסבר ב-1.1; חיבור תעשייתי עמוק יותר; שאלה שנייה
  לקריאת סקאלה לוגריתמית (3.4).

**שיטת העבודה שהוכיחה את עצמה:** לכל חתיכה — לזהות את **הטעות הנפוצה** של הסטודנט,
ולבנות ויכוח שבו זרובבל ותרצה מכריחים אותו להתעמת איתה. (לדוגמה מופתית: ב-1.1
זרובבל אומר "זה אותו קו, פשוט נאריך אותו" — וזו בדיוק הטעות, ותרצה מפרקת אותה.)
