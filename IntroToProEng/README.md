# IntroToProEng — תכנים לקורס מבוא להנדסת תהליכים

תיקייה זו מאחסנת תכנים דיגיטליים שאנחנו מכינים לקורס *מבוא להנדסת תהליכים*
(לומדות, תרגולים אינטראקטיביים וכו'), בנפרד מריפו הספר עצמו.

## תוכן

- **`lomda/`** — לומדת SCORM ללמידה עצמית: *מדידה והתאמת עקומות* (פרק 2).
  מונעת-נתונים: `content.js` מכיל את כל הטקסט, `index.html` הוא המנוע.
- **`lomda_scorm.zip`** — חבילת SCORM 1.2 מוכנה להעלאה ל-Moodle.
- **`source-deck-chapter2.pptx`** — המצגת המקורית שממנה נבנתה הלומדה.
- **`HANDOFF.md`** — מסמך ההעברה: כל ההחלטות, הארכיטקטורה והמצב הנוכחי. **להתחיל מכאן.**
